# Number Guessing Game - Python 🎯

A terminal-based number guessing game where the computer randomly selects a number within a range you define, and you try to guess it!

## 💡 Features
- User-defined lower and upper range
- Random number generation
- Tracks number of attempts
- Hints provided (too high / too low)
- Congratulates user upon correct guess

## 🎮 How to Play
Enter a lower and upper bound to set the range.

Guess numbers based on hints until you find the correct one.

The game tells you how many attempts you took.

##❗ Notes
Input must be integers.

Runs in the terminal/command prompt.

Simple and great for beginners!
